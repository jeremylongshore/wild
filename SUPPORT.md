# Support

## Getting Help

- **Documentation**: Check the [README](README.md) and [000-docs/](000-docs/) directory
- **Bug Reports**: [Open an issue](https://github.com/jeremylongshore/wild/issues/new?template=bug_report.md)
- **Feature Requests**: [Open an issue](https://github.com/jeremylongshore/wild/issues/new?template=feature_request.md)
- **Discussions**: [GitHub Discussions](https://github.com/jeremylongshore/wild/discussions)
- **Security Issues**: See [SECURITY.md](SECURITY.md) — do NOT open public issues

## Response Times

| Channel | Response Time |
|---------|--------------|
| Security reports | 24 hours |
| Bug reports | 3 business days |
| Feature requests | 1 week |
| General questions | 1 week |

## Before Opening an Issue

1. Search [existing issues](https://github.com/jeremylongshore/wild/issues) first
2. Check the [documentation](000-docs/) — especially [ADR-0001](000-docs/adr/ADR-0001-topology.md) for the topology rationale and [ADR-0002](000-docs/adr/ADR-0002-namespace-extraction-policy.md) for the namespace-extraction policy
3. Include Ruby + Rails versions and reproduction steps
4. Name the affected `Wild::` namespace explicitly
